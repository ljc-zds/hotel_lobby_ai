## Report a problem

Include the page URL, the steps you took and what happened. Screenshots can help, but remove personal information first. Do not send passwords, payment details or private photos.

## Template support channel

A support email and message receiving service have not been configured for this template. Set up your own support channel before launch. This page does not send messages to the reference website.

## Account and creations

Find your [account settings](/settings) or the current browser’s [demo videos](/orders).

## Common questions

If credits or creations appear empty, check that you are using the same browser. Demo data is stored locally and does not sync between devices. The demo does not generate real AI video.
