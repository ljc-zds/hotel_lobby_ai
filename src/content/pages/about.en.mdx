## Two photos, one shared stage

This project gives friends, couples, pet owners and creative teams a way to explore two-subject music videos. Choose a scene, add two photos and select an output resolution.

## What is included

- Fourteen music scenes with category browsing.
- Local photo previews, swapping and resolution selection.
- Demo creation history and credit packs.
- English and Chinese content pages, guides and articles.

## A transparent demo

This is an independent template built with ShipAny, not an official service of the reference website. Generation is simulated, and no real AI or payment integration is enabled. Photos remain in browser memory.

## Video generation model

**Current model: none — demo mode.** No video generation API is called. The interface simulates completion and creates a local demo entry; it does not produce a new AI video. Before real generation is enabled, this page and the creation interface will name the actual provider and model version.
